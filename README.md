

\# Exploratory Analysis with a Finding



\## Project Overview

Exploratory Data Analysis of retail sales data to identify meaningful business insights.



\## Objectives

\- Analyze sales and profit.

\- Investigate the relationship between discounts and profit.

\- Compare product category and regional performance.

\- Identify evidence-based business findings.



\## Tools and Technologies

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Jupyter Notebook

\- Streamlit



\## Project Files

\- Jupyter Notebook: Exploratory analysis

\- visualizations/: Charts and graphs

\- reports/: Business findings

\- requirements.txt: Required Python packages



\## How to Run

1\. Install packages using pip install -r requirements.txt.

2\. Place the dataset in the project folder.

3\. Open the notebook in Jupyter Notebook.

4\. Run the notebook cells in order.
